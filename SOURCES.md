ingestion report in the app's *Knowledge base* drawer.

## Synthetic test material (not real law)

Some tests and evaluation scenarios use short made-up texts, labelled as synthetic in the code,
to exercise behaviour that the real Act cannot trigger:

| Where | Content | Purpose |
|---|---|---|
| `Backend/test/*.test.js` | "Sample Town / Sample County" bylaw snippets | ingestion noise, uploads, sessions, pipeline behaviour |
| `Backend/src/eval/runEval.js` | two "town fees" snippets that disagree (500 vs 800 shillings) | conflicting-evidence scenario |
| `Backend/src/eval/runEval.js`, `Backend/test/documents.test.js` | noisy copy of the real Act (page numbers, running headers, tabs, CRLF added) | noise-robustness check; words of the law unchanged |

## User-provided documents

Documents citizens upload on the main page are private to their browser session, held in memory
only, never written to disk, and deleted after 1 hour of inactivity. They are not part of this
knowledge base and are not sent anywhere except, as passages, to the configured language model
when that user asks a question.

## Language model

Answers are generated by the model configured in `LLM_*` environment variables (currently
Groq-hosted `qwen/qwen3.8-27b`, fallback `openai/gpt-oss-20b`). Only the question and the
